# 사도행전의 전도 여정 · 인터랙티브 지도

사도행전을 따라 **다섯 여정** — 빌립의 전도(행 8장)와 사도 바울의 1·2·3차 전도여행 + 로마 압송(행 13–28장) — 을
실제 지도 위에서 공부하는 웹앱입니다.
지명은 개역개정 표기를, 좌표는 고대 도시 유적지를 기준으로 합니다.

## 기능
- **인트로 화면** — 클릭/Enter로 진입, 진입 시 전체 경로를 먼저 보여 줌
- **여정 탭** — 빌립(전도자)·1차·2차·3차·로마(압송)·전체 한눈에
- **실제 지도** — Esri Light Gray 현대 지도 ⇄ DARE 로마 시대 고지도 토글, 부드러운 휠 줌
- **경로 애니메이션** — 선 그리기(stroke reveal) + 흐르는 점선(진행 방향), 왕복 구간은 옆으로 갈라져 표시
- **전진/귀환 구분(1차)** — 나아간 길(실선)과 되짚어 온 길(초록 점선)을 버튼으로 각각 강조
- **마커** — 지명 라벨 항상 표시, 출발(▶)/도착(⚑) 글리프, 재방문 병합 + 횟수 배지, 선택 시 펄스 글로우
- **여행 개요 사이드바** — 연대·본문·동행 메타, 요약, 경유지 타임라인(지역·현대 지명 병기)
- **지역 상세 패널** — 현대 위치 · 도시 성격 · 성경 본문 · 있었던 일 · 테마 콜아웃 · 동행자 · 동역자 이야기
- **말씀 검색** — 사이드바 검색창(단축키 `/`)에서 세 가지 방식으로 찾습니다.
  - *구절* — `행 16:9` · `사도행전 13:1-3` · `16장` · `13-14장` · `27:39-28:10` → 그 본문(개역개정)과 그 말씀이 일어난 지도 위 정차지를 함께 표시
  - *말씀 속 낱말* — `마게도냐` · `에디오피아 내시` → 해당 절과 관련 정차지·인물·서신
  - *지명 · 인물 · 서신 이름* — `루스드라` · `실라` · `갈라디아서`
  꼭 맞는 결과가 없으면 조사를 뗀 형태, 그다음 일부만 맞는 결과 순으로 넓혀 찾고 그 사실을 알립니다.
  결과(절 카드·정차지·칩 어느 쪽이든)를 누르면 해당 여정을 켜고 그 자리로 지도를 옮긴 뒤,
  **지도에 말풍선으로 위치를 찍고**(여정 · 지명 · 본문 범위 · 찾은 절) 상세 패널을 열며,
  **그 구절의 본문을 자동으로 펼쳐** 찾던 절을 표시해 줍니다.
  말풍선은 상세 패널을 닫아도 남아 있어, 좁은 화면에서도 위치를 확인할 수 있습니다.
- **본문 펼쳐 보기** — 상세 패널의 성경 본문 표시(`행 13:1-3` 등)를 누르면 그 구절의 개역개정 본문이 그 자리에서 펼쳐집니다.
- **인물 약전** — 동행자 칩 클릭 시 베드로·요한·바나바·실라·디모데·누가 등 약전 카드
- **관련 서신** — 서신 칩 클릭 시 기록 시기·수신자·주제·요약 카드. 칩의 **수신** 배지는 그 도시로 보낸 편지, **기록** 배지는 그 도시에서 쓴 편지
- **전체 보기 통합 패널** — 한 도시를 여러 여정이 방문한 경우 여정별 기록을 한 패널에 표시
- **반응형** — 961px 이상은 좌우 배치(사이드바 · 지도 · 우측 상세 패널), 960px 이하는 상하 배치 + 하단 시트. 폰 가로(높이 560px 이하)는 좌우 배치를 유지하고, 태블릿 구간(768~960px · 높이 561px 이상)은 여정 탭 6개를 한 줄로 펴서 경로 목록을 59px 더 보여 준다.
- **전체화면 버튼 · 사용법 모달 · Esc 닫기**
- **빌드 불필요한 정적 사이트** (HTML/CSS/JS). Leaflet·지도 타일·글꼴은 CDN 사용 → 실행 시 인터넷 필요.

## 보기
- **가장 간단:** `index.html`을 브라우저로 직접 열기 (더블클릭).
- (선택) 로컬 서버로 보고 싶으면: `npm run dev` → http://localhost:5173

## 배포 (Vercel)
1. 이 폴더를 깃 저장소로 만들어 GitHub에 올립니다 (`node_modules`는 `.gitignore` 처리됨).
2. Vercel에서 import → 프레임워크 **Other**, 빌드 명령 없음, 출력 디렉터리 루트(`.`).
3. 배포 완료.

## 구성
```
index.html        화면 구조 (인트로 · 헤더 · 사이드바 · 지도 · 상세 패널 · 모달)
css/styles.css    뉴모피즘(Soft UI) 테마 · 마커/패널/애니메이션 스타일
js/data.js        여정·경유지·본문·도시 정보 데이터 (행 8장 · 13–28장)
js/people.js      동행자 인물 약전 (칩 클릭 카드)
js/epistles.js    정차지별 관련 서신 매핑(수신/기록 구분) + 서신 요약
js/acts-text.js   사도행전 본문(개역개정) 28장 1006절 — 검색·본문 펼침용
js/app.js         Leaflet 지도 · 경로/마커 · 사이드바 · 상세 패널 로직
js/search.js      말씀 검색 — 구절 파서 · 본문/정차지 색인 · 결과 목록 · 본문 펼침
```
> `js/acts-text.js`는 개역개정 사도행전 전문입니다. 개역개정에는 24:7이 없어 총 1006절입니다.
> 검색은 `js/search.js`가 `app.js`의 `window.ActsMap.focusStop(여정id, 정차번호)`을 불러 지도를 옮깁니다.
> 참고: `package.json`/`vite.config.js`는 로컬 개발 서버(`npm run dev`)용 선택 사항이며, 앱 실행에 꼭 필요하지는 않습니다.

데이터를 보강하려면 `js/data.js`의 각 여정 `stops` 배열에 항목을 추가하면 됩니다.
서신 매핑은 `js/epistles.js`의 `PAUL_EPISTLE_BOOKS`에서 `"여정id-정차번호"` 키에
`{ book: "책이름", rel: "수신" | "기록" }` 항목으로 조정합니다.

## 지도 타일
현대 지도는 **Esri Light Gray Canvas**(바탕 + 지명 라벨 두 레이어)를 씁니다.
2026년부터 CARTO 무료 타일이 이미지에 "API KEY REQUIRED" 워터마크를 찍기 시작해 옮겼습니다.
Esri 기본 타일은 키 없이 쓸 수 있고, 출처 표기는 지도 아래 크레딧과 Leaflet attribution에 있습니다.
바꾸려면 `js/app.js`의 `modernTiles`(레이어 묶음)만 교체하면 됩니다.
